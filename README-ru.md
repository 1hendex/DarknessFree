### Что такое Darkness Free?

Darkness Free — бесплатная версия Darkness Liquidation.
Плагин не включает полный функционал. Полная версия: [https://darkness.rip](https://darkness.rip)

Darkness является форком [GrimAC](https://github.com/GrimAnticheat/Grim). В его основе
лежит предиктивный движок GrimAC, расширенный собственными проверками, модулями защиты клиента,
административными инструментами, темами, наказаниями и интеграциями.

### Требования

- Java 17 или новее для запуска плагина.
- Сервер, совместимый с Paper. Folia поддерживается.
- ~~Действующая лицензия Darkness — укажите её в `plugins/Darkness/config.yml` после первого запуска.~~ (Не требуется в бесплатной версии. Полная версия: [https://darkness.rip](https://darkness.rip))
- JDK 21 или новее для сборки проекта из исходного кода.

### Установка

1. Скачайте Darkness Free или приобретите полную версию на [darkness.rip](https://darkness.rip).
2. Поместите `Darkness.jar` в папку `plugins` вашего сервера.
3. Один раз запустите сервер, чтобы создать файлы конфигурации.
4. Проверьте настройки проверок, наказаний, темы, логирования и интеграций.
5. Перезапустите сервер или выполните `/darkness reload` после изменения конфигурации.

### Возможности

- Предиктивные проверки движения, aim, reach, velocity, inventory, scaffold, timer, elytra,
  транспорта, пакетов и других механик.
- Защита от некорректных пакетов, краш-попыток, подозрительных данных клиента, blink-подобного
  поведения и других злоупотреблений протоколом.
- ~~Модули скрытия информации, уменьшающие преимущества чит-клиентов через подмену выбранных данных,
  видимых клиенту.~~ *(Недоступно в бесплатной версии. Полная версия: [darkness.rip](https://darkness.rip))*
- Мониторинг брендов клиентов и правила для подозрительных или запрещённых клиентов.
- Алерты, verbose-вывод, профили игроков, метрики производительности, логи, Discord-вебхуки и
  пересылка алертов через прокси.
- Настраиваемые наказания, punishment wave, инструменты для модерации, темы и конфигурации на английском,
  русском и украинском языках.
- Необязательные интеграции с ViaVersion, ViaBackwards, Geyser, Floodgate, LuckPerms и
  PlaceholderAPI.
- Поддержка Paper и Folia.

### Предиктивный движок

Darkness Liquidation построен на предиктивной основе GrimAC. Вместо проверки только простых лимитов
пакетов движок воссоздаёт набор движений, которые ванильный клиент мог выполнить легитимно, и
сравнивает входящие действия с этой моделью.

- **Симуляция ванильного движения.** Учитываются ходьба, плавание, отбрасывание, паутина,
  пузырьковые колонны, транспорт, элитры и другие механики ванильного Minecraft.
- **Физика и коллизии с учётом версий.** Обрабатываются различия версий клиента и сервера, порядок
  коллизий, изменения хитбоксов, блоки-замены ViaVersion и данные блоков, зависящие от версии.
- **Репликация мира для каждого игрока.** Античит создаёт кэш клиентского представления мира из
  пакетов чанков, установки и изменения блоков. Это позволяет безопасно учитывать пакетные и
  поддельные блоки без автоматических ложных срабатываний.
- **Компенсация задержки и inventory.** Изменения мира, состояния игрока и данные inventory
  учитываются в порядке их получения клиентом, что снижает ложные срабатывания из-за пинга,
  ghost blocks и рассинхронизации.
- **Асинхронная архитектура.** Большая часть обработки движения и слушателей работает рядом с
  сетевым конвейером; данные игроков рассчитаны на безопасный параллельный доступ и масштабирование.
- **Безопасность за счёт точной симуляции.** Проверки сопоставляют действия с возможным ванильным
  поведением, чтобы отличать недопустимое движение без опоры только на скрытность логики.

### API для разработчиков

Darkness предоставляет API для интеграции с пользовательскими плагинами и серверными системами.
Оно позволяет создавать расширения вокруг событий и возможностей Darkness, не завися от внутренних
деталей реализации.

- Репозиторий API и документация: [1hendex/DarknessAPI](https://github.com/1hendex/DarknessAPI)

### Конфигурация

Основные файлы создаются в `plugins/Darkness/`. Исходные конфигурации в репозитории:

- [`config/ru.yml`](common/src/main/resources/config/ru.yml) — общие настройки, алерты, защита клиента,
  Discord, логи, наказания и интеграции.
- [`checks/ru.yml`](common/src/main/resources/checks/ru.yml) — проверки античита и их параметры.
- [`punishments/ru.yml`](common/src/main/resources/punishments/ru.yml) — правила наказаний за нарушения.
- [`themes/`](common/src/main/resources/themes) — темы алертов и сообщений.

Меняйте параметры постепенно и проверяйте их на своём сервере, прежде чем включать строгие наказания
на продакшене.

остальные — алиасами. После изменения настройки перезагрузите сервер. Аргументы в `<угловых

### Сборка из исходного кода

```bash
git clone https://github.com/1hendex/DarknessFree.git
cd DarknessFree
./gradlew shadowJar
```

В Windows используйте `gradlew.bat shadowJar`. Готовый JAR будет находиться по пути:

```text
build/libs/Darkness.jar
```
